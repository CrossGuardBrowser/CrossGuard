核心特性

为多账号运营而生的完整工具链

从环境隔离到指纹伪装，从代理到 AI 自动化，CrossGuard 覆盖指纹浏览器的每一个关键环节。

多环境隔离

每个环境拥有独立的用户数据目录与 Cookie/缓存，环境之间完全隔离、互不干扰，无限多开。

全维度指纹伪装

UA 字符串使用 138.0.0.0，Client Hints 的完整版本与 GREASE 品牌对齐 Chromium 138。Win10 与 Win11 共用这条 UA，区别只在 platformVersion。

代理与 DNS 防泄露

支持 HTTP / HTTPS / SOCKS4 / SOCKS5 代理，内置 DNS 防泄露与 Host 解析规则，杜绝 IP 与 DNS 真实身份外泄。

Cookie 注入

通过 CDP 注入 Cookie（兼容 EditThisCookie 格式），一键导入会话，无需重新登录。

NEW

MCP AI 自动化

36 个 MCP 工具覆盖环境、页面读取、点击填写、标签页和文件导出。侧栏可接入 OpenAI 兼容模型，密钥留在本机。

NEW

云端环境同步

搭配 CrossGuardServer，同一账号多主机保持环境一致，书签与浏览历史云端同步，随时切换设备。

NEW

RPA 流程

32 种步骤：导航、点击、提取、条件、循环、文件与 Webhook。支持手动运行、每天定时、间隔执行，以及把页面操作录成步骤。

扩展与插件

从本地包或 Chrome / Edge 商店安装扩展，按环境勾选加载。每个环境仍使用独立的用户数据目录。

常见问题

FAQ

CrossGuard 是免费的吗？

是的。CrossGuard 完全开源免费，源码与所有发布版本均托管在 GitHub（sunny5156/CrossGuard）。

基于 Chromium 哪个版本？支持什么系统？

当前安装包版本为 v2.4.7，内核是自编译的 Chromium 138.0.7204.50。支持 Windows 10 / 11。界面里的 Windows 7 / 8 选项会输出与 Windows 10 相同的 UA，因为 Chrome 138 不能运行在这些系统上。

“指纹伪装”具体包含哪些维度？

UA 字符串是 Chrome/138.0.0.0，Client Hints 的完整版本是 138.0.7204.50，GREASE 品牌按这个主版本计算。语言在进程启动前按代理出口写入。Canvas 与 WebGL 的噪音是按环境固定的像素偏移，同一环境多次读回一致。字体列表可以保存在配置里，当前内核仍使用本机字体。

什么是 MCP AI 自动化？怎么用？

管理界面可启动 MCP 服务（127.0.0.1:18901），Token 写在本机。36 个工具分成环境管理、页面读取与操作、标签页和文件导出。配置 .mcp.json 后，可在 Claude Code、Cursor 等客户端里用自然语言驱动对应环境。RPA 是另一套可定时的步骤流程，不经过 MCP。

书签 / 历史 / Cookie / 密码能跨设备同步吗？

搭配 CrossGuardServer 可实现同一账号多主机环境同步：当前已支持 书签 + 浏览历史 的云端同步。Cookie 与账号密码因涉及本机密钥绑定（App-Bound Encryption），将在后续版本通过 CDP / 密钥搬运方案支持。

如何快速开始使用？

① 从 GitHub Releases 下载安装包；② 安装并启动 CrossGuard；③ 新建一个环境；④ 配置指纹与代理参数；⑤ 点击启动即可使用。环境数据互相隔离，可无限多开。
